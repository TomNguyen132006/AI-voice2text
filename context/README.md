# Context folder

Short, token-cheap context for AI assistants and teammates. Read these instead of the
backlog .docx or the full README.

| File | Read when | Contents |
|---|---|---|
| [project.md](project.md) | Every session | What the app does, pipeline, stack, key facts (model IDs, URLs, decisions), status |
| [backlog.md](backlog.md) | Picking or checking a story | All Epics 0-10, user stories, "Done when" criteria, due dates |

Rules:
- Keep these files short. Facts only, no long explanations.
- When a story is finished or a key fact changes (model ID, URL, decision), update `project.md`.
- If the backlog .docx changes, update `backlog.md` in the same commit.
- Details live in the real files: `README.md`, `docs/DECISIONS.md`, `backend/schemas.py`.
