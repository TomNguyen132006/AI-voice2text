## Pure Quadratic Example
_Lecture time 00:00 - 01:45_

- A pure quadratic is a quadratic function of the form f(x)=ax^2+bx+c with a≠0, whose graph is a parabola.  
  🌐 [Quadratic Models and Optimization (Max/Min) | Varsity Tutors](https://www.varsitytutors.com/practice/subjects/ap-physics-1/lessons/quadratic-models-and-optimization-max-min)
- The function is a pure quadratic in two variables, x and y.  
  📍 00:19-00:21, 00:22-00:27
- Any pure quadratic in two variables can be written as x^T S x where S is a symmetric 2×2 matrix.  
  📍 00:27-00:42
- In this example, S is diagonal and its eigenvalues are 1 and b.  
  📍 00:42-00:49
- Here b represents the smaller eigenvalue of S.  
  📍 00:49-00:52
- For a symmetric positive matrix, the condition number is the ratio of its largest to smallest eigenvalue.  
  🌐 [Condition Number of the Hessian](https://www.math.cmu.edu/~shlomo/VKI-Lectures/lecture1/node5.html)
- The condition number of S is λ_max/λ_min = 1/b.  
  📍 00:53-01:10, 01:10-01:16
- When b is very small, 1/b is large, indicating a high condition number and slow convergence.  
  📍 01:16-01:24
- An eigenvalue is the factor by which an eigenvector is stretched or compressed during a linear transformation.  
  🌐 [Eigenvalues and eigenvectors - Wikipedia](https://en.wikipedia.org/wiki/Eigenvalues_and_eigenvectors)
- Gradient descent is a first‑order iterative algorithm that uses the gradient to minimize a differentiable function.  
  🌐 [Gradient descent - Wikipedia](https://en.wikipedia.org/wiki/Gradient_descent)

## Gradient Hessian Connection
_Lecture time 03:06 - 09:59_

- The gradient of the linear function f(x,y)=2x+5y is the constant vector (2,5).  
  📍 03:53-03:58, 03:59-04:10
- Because the gradient is constant, it is the same at every point (x,y).  
  📍 04:10-04:24, 05:47-05:54
- The gradient direction indicates the steepest ascent; moving perpendicular to the level set increases the function fastest.  
  📍 05:56-06:01, 06:01-06:08, 06:08-06:11, 06:11-06:13, 06:13-06:15, 06:41-06:48
- For f=2x+5y, the level set where f=0 is the plane 2x+5y=0; staying in this plane keeps the function value constant.  
  📍 06:27-06:34, 06:36-06:38, 06:41-06:48, 06:49-06:55, 07:19-07:20, 07:20-07:24
- A level set of a function is the set of points where the function has a constant value; for two variables it is a level curve or contour line.  
  🌐 [Level set - Wikipedia](https://en.wikipedia.org/wiki/Level_set)
- The Hessian matrix consists of second‑order partial derivatives; for this linear function all second derivatives are zero, so the Hessian is the zero 2×2 matrix.  
  📍 04:10-04:24, 04:24-04:30, 04:35-04:36, 04:36-04:38, 04:38-04:38, 04:46-04:50
- The Hessian matrix describes the local curvature of a function.  
  🌐 [Hessian matrix - Wikipedia](https://en.wikipedia.org/wiki/Hessian_matrix)
- The lecturer asks how the Hessian relates to the convexity of the function.  
  📍 09:46-09:52, 09:53-09:57
- Geometrically, a function is convex if a line segment drawn from any point (x, f(x)) to another point (y, f(y)) lies above or on the graph of the function.
